# SVALKA 🧥

Merge-игра про управление винтажным секонд-хенд магазином. Собирай шмот, мержи одинаковые вещи, продавай за профит!

## 🎮 Играть

Открой `index.html` в браузере или задеплой на любой хостинг статики.

**Для Яндекс Игр:** используй сборку в одном файле или настрой Yandex Games SDK.

## 🕹️ Геймплей

### Склад (Merge)
- Покупай **тюки** с одеждой
- Перетаскивай одинаковые вещи друг на друга для **merge**
- Грейды: 🟢 Масс → 🔵 Базовый → 🟣 Хороший → 🟠 Редкий → 🔴 Грааль
- Продавай всё разом или выставляй на аукцион

### Тюки
- **Европа** (₽100) — базовый микс
- **Япония** (₽350) — качественнее
- **USA** (₽500) — шанс редкого
- **СССР** (₽1000) — шанс грааля

### Байеры
- Отправляй байеров на закупку
- Локации: Бабушкин чердак, Блошиный рынок, Заброшенный склад
- Пассивный фарм вещей

### Аукцион
- Выставляй вещи на аукцион
- NPC делают ставки
- Можешь ждать лучшую цену (но покупатели могут уйти!)

### Ивенты
- **День воровства** — хватай вещи бесплатно в течение 30 секунд!

## 🛠️ Технологии

- Vanilla JS
- CSS3
- localStorage для сохранений
- Готово для интеграции с Yandex Games SDK
